PRICEWISE — PRICING TABLE WITH MONTHLY/YEARLY TOGGLE
====================================================

Project type:
Responsive front-end website using HTML, CSS and JavaScript.

FEATURES
--------
1. Three pricing plans: Starter, Professional and Business.
2. Monthly / Yearly toggle.
3. Yearly pricing displays a 20% discount on paid plans.
4. Prices update instantly using JavaScript.
5. Responsive layout for desktop, tablet and mobile.
6. Hover effects, FAQ accordion and navigation links.
7. No frameworks or backend required.

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open the "pricing_table_project" folder.
3. Double-click index.html.
4. The project opens in your browser.
5. Click Monthly and Yearly to test the pricing toggle.

FILES
-----
index.html  - Website structure
style.css   - Styling and responsive layout
script.js   - Monthly/yearly toggle functionality

NOTE
----
This is a front-end demonstration project. The plan names and prices are sample data.
Buttons are demonstration links; no real checkout or subscription is connected.
